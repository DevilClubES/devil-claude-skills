# Optional Connectors

The `~~...` labels in these skills describe connector capabilities, not literal commands.

| Placeholder | Typical source | Use |
|---|---|---|
| `~~design tool` | Figma or another design workspace | Frames, variables, components, measurements, and assets |
| `~~knowledge base` | Notion, Confluence, Google Drive, or SharePoint | Approved guidance, decisions, and existing documentation |
| `~~project tracker` | Jira, Linear, or GitHub Issues | Tickets, acceptance criteria, and handoff tasks |
| `~~user feedback` | Research repository, support system, surveys, or email | Evidence behind UX findings and priorities |

Use a connected source only when its tool is available in the current session. If it is unavailable, continue with repository files and user-provided artifacts, state the limitation, and never imply that external data was retrieved.
