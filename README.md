# devil-claude-skills

Curated marketplace of Claude Code skills used at [Devil Club](https://devil.club).

## Plugins

### `design-skills`

Seven standalone skills for design, UX, accessibility, and research work:

| Skill | Use it for |
|---|---|
| `/design-critique` | Structured feedback on usability, hierarchy, consistency |
| `/design-system` | Audit/document/extend a design system |
| `/design-handoff` | Generate developer handoff specs from a design |
| `/accessibility-review` | WCAG 2.1 AA audit of a design or page |
| `/ux-copy` | Write or review microcopy, error messages, empty states, CTAs |
| `/user-research` | Plan, conduct, and synthesize user research |
| `/research-synthesis` | Synthesize interview/survey/test results into themes |

## Install

In any Claude Code session:

```
/plugin marketplace add DevilClubES/devil-claude-skills
/plugin install design-skills@devil-claude-skills
```

Restart Claude Code. The seven slash commands are available everywhere.

## Update

```
/plugin update design-skills@devil-claude-skills
```
